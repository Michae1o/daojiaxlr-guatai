# 判据从哪来

## 一句话

这个软件怎么起卦、怎么排盘、六宫怎么说、断辞怎么写，全部来自 `apps/shared-judgment/corpus/`
下的九份体系文档（`00_总纲与索引` … `08_依据与讲者分级`，约 23.7 万字）。文档是人读的，
跑 `node tools/gen-corpus.mjs` 之后变成代码里的 `src/corpus.js`。

想换一套判据、改成你自己的理解，改 md 再重跑一次就行，没有任何地方会拦你。

## 数据怎么流动

```
apps/shared-judgment/corpus/00…08.md      ← 人读的真源（Markdown）
   └─ node tools/gen-corpus.mjs ─→ src/corpus.js        ← 打包成 JS，代码读这个
        ├─ src/prompt.js     SYS：解卦用的系统提示词
        ├─ src/judgment.js   判据正文：G 六宫固定层 / COMMON 通用 / YQ 应期 / CATS 十类事类 / buildBlocks 断卦块
        └─ src/asks.js · asks-more.js   本机速断的按问法素材（{ plain, tx, src }）
```

- **改判据只改 corpus 里的 md**，然后重跑 `gen-corpus.mjs`；`src/corpus.js` 是产物，别手改。
- 每条判据的出处写成 `corpus/0X §N`（`N` = 语料里的小节号），界面上「出处：…」显示的就是它。
- 算法部分（走宫 `cast.js`、历法、五行生克、体用计算）不是判据文本，改不改随你。

## 提示词与语料是对齐的

`src/prompt.js` 的 SYS 与上面五条口径一致：

| 项 | 提示词写的是 | 语料依据 |
|---|---|---|
| 体用 | 体＝落宫，用＝起卦时辰 | 08 原记录 第 5 条、03 原记录 |
| 藏干 | 用的少；日常断事以六宫宫义为主线，取象、转太极点时按藏干表取 | 01「七·零」 |
| 天气应期 | 只到时辰；问会不会只答会不会，问天气如何才描述；温度两说不硬套 | 04 原记录 |

改提示词只需改 `src/prompt.js`，改完重跑前端构建即可，不需要同步别的文件。

## 这一版换掉了什么

| 项 | 处理 |
|---|---|
| `CATS` 十一类事类 | 按 `corpus/04` 逐类重写，出处换 `corpus/04 §N`；语料没写的写成「材料未给」 |
| `ASKS` / `ASKS_MORE`（70 条素材） | `plain` 换白话转写、`tx` 换逐字原话、`src` 换 `corpus/…` |
| `buildBlocks` 的出处锚 | 37 处全部换成语料锚 |
| `COMMON.body`（体用）、`COMMON.shengke`（旺衰两说） | 按语料口径重写 |
| `G` 六宫固定层、`YQ` 应期 | 与语料一致，未改 |

## 自己验一下

```bash
node tools/gen-corpus.mjs                 # 语料 → src/corpus.js（改了 md 就跑这个）
cd apps/desktop-web && npm run build:shell   # 桌面端单文件（再按 BUILD.md 打进 exe）
```
