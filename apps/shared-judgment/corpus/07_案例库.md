# 07 案例库

> 这份文档管的是“**别人是怎么断的**”。规则分散在 03、04、05 各卷，这里只放**整局**：
> 谁问、问的什么原话、怎么起出来的三宫、维护者亲口怎么断、这一步一步能不能重走、最后应没应。
> 用法有三种：① 学断法时照着走一遍推导链条；② 校验自己起的盘与断语是否同路；③ 查一句话到底是不是维护者说的（本卷每条断语都标了讲者级别）。

## 凡例

- **案例序号** `C-01`…`C-18` 只在本库内部互相引用用，不作别处编号。
- **讲者级别**：`A 维护者` ＝ 邵一尘本人（含四明居士、邵一尘、秋叶飘零、四明闲农等署名，同一人）；
  `C 学员` ＝ 群友／学员／卦主，**只作案例实况，不作规则**；`待定` ＝ 判不出是谁。
  同一案里学员的话与维护者的话分开记，学员说法一律不进“推导链条”。
- **引文**：一律逐字，错字、异体、繁简照留，出处写（材料名:行号）。概括写在“推导”里，不塞进引号。
- **应验**：原文有卦主／事主反馈就照记，没有就写“材料未给应验”——**没有反馈的案子不算验过**。
- **可复算**：三宫、时辰、断语、推导都齐、能重走一遍，才叫可复算。只给宫位、不告取数的，标“宫位可复算”。

## 二、逐案

### 甲、宗门与拜师

#### C-01 问“邵师傅会不会收我为徒”

- **何人问／所问原话**：竹清道人（群友、求测者，C 级）。「卦求，邵师傅会不会收我为徒。」（20_讲课_2012年5月10日邵老师断卦辞编.txt:18）
- **起卦**：子时入课，按问课人所在地的时间取子时；三数未给出。「問邵先生是否收竹青兄為徒，子時入課赤口、留連、大安」（20_讲课_2012年5月10日邵老师断卦辞编.txt:40）；问为何取子，维护者答「我按照問課人的時間來斷的，所以取了子」（20_讲课_2012年5月10日邵老师断卦辞编.txt:116）。
- **三宫**：天宫赤口　地宫留连　人宫大安；子时。
- **断语要点**（全为 A 维护者）：
  - 天宫：「天时赤口克大安，为不得时运，但克为考察，说明从天时来看，还得考察一阵子」（20_讲课_2012年5月10日邵老师断卦辞编.txt:84）
  - 地宫：「留连土，大安人宫克地利环镜，为得势，说明现在的环镜利于他拜师学习」（20_讲课_2012年5月10日邵老师断卦辞编.txt:90）｜「但留连本为停留的意思，虽地利得势，但也还是需要一段时间」（20_讲课_2012年5月10日邵老师断卦辞编.txt:94）
  - 人宫／结果：「最后落宫大安，为吉，说明此事可谋，但大安身未动，说明老师现在尚未有收徒之意，自己还需多加努力。」（20_讲课_2012年5月10日邵老师断卦辞编.txt:102）
  - 时辰：「子时用生体，事件倒还是呈良性发展，有贵人相助」（20_讲课_2012年5月10日邵老师断卦辞编.txt:130）
  - 落宫指谁：「大安是事主，但是你问的是动态的，当然，答案也是在动态的状况中，而非单指事主本人，而是指事件。」（20_讲课_2012年5月10日邵老师断卦辞编.txt:120）
  - 学员说法（C 级，不作规则）：遊塵散人先解「其一，天宮赤口，緣分有損，且傷人宮大安，乃“天不助我”之意。」（同:69）「其二，地宮留連，發展堦段，人克地。自己努力程度加深，但依舊摸不招邊際，暫時見不得陽光。」（同:70）；天天天蓝另起一套三宫「空亡，速喜，留连，子时。天时空亡，现在收徒为时太早。天顺人意，说明虽现在不能成功却也我了缘份。地利速喜生人种，想见即是缘，老师对你印象还行。人种留连，自身在求学上出现迷茫，停滞不前。虽然都有助力，」（同:110）。维护者只以「嗯，大致都对」（同:76）收下学员的解，未裁断两套起卦的对错。
- **推导链条**（可重走）：
  1. 落宫大安 → 大安身未动 → 老师那边没有动，眼下未起收徒之念；但大安为吉，事“可谋”。
  2. 天宫赤口（金）克人宫大安（木）→ 克不按凶读，此案取“考察”义 → 还要被看一阵子。
  3. 人宫大安（木）克地宫留连（土）→ 人克地 → 地利得势 → 现在的环境利他学习。
  4. 留连本义为停留 → 纵使得势，也要一段时间。
  5. 时辰子（水）生大安（木）→ 用生体 → 整件事的趋势良性、有贵人。
- **应验**：材料未给应验（此卦收尾即散场，没有拜师结果反馈）。
- **本案的口径价值**：立“克为考察”一义（学员当场表示受教），是“克不作凶看”的第 1 号例证；示范天时、地利、人和三宫各读一义而不混读；并纠正“落宫＝事主本人”的死读法——问动态之事，落宫指事件。

### 乙、日常琐事与定时

#### C-02 刚才去玩牌咋样、坐何方位

- **何人问／所问原话**：竹清道人（群友、卦主，C 级）。「大家算一下，我刚才去玩牌咋样」（21_讲课_2012年5月11日邵老师解卦案例.txt:2）。玩牌时间由卦主给出：「21：50----22：45」（同:287）。
- **起卦**：按时间起。「按时间算，得：速喜、留连、留连」（同:22）。会后更正：「22应该是赤口，而非速喜」（同:171）。三数未给出，只给宫位。
- **三宫**：初断 天宫速喜　地宫留连　人宫留连；更正后 天宫赤口　地宫留连　人宫留连。亥子时分。
- **断语要点**：
  - 赌运成套断辞（A 维护者）：「我们在断赌运的时候，大安为平，略赢；留连为平、略输；速喜为赢，但时间不亦长，过时为泄，特别是晚上赌；」（同:92）「赤口为大输，小吉为大赢，但时间长，细水长流，时短为小赢，空亡为大输或不输不赢」（同:94）
  - 方位（A 维护者）：「断所坐方位不是断最后一宫的，而是断开始时的一宫，因为开始时坐的位嘛」（同:229）｜「除非之后换了，那么再看其它宫位」（同:231）｜「嗯，赤口起为西位」（同:225）｜「为什么说是西北呢，因为近北为水，水才耗金嘛」（同:233）
  - 学员说法（C 级）：遊塵散人解初断卦「大體上看，牌運不錯。因爲天生人，天為運氣。」（同:68）「不過，落宮留連，説明“戰況”焦灼，各有勝負。」（同:69）「綜上，打牌勝敗參半，勝多輸少」（同:74），维护者只评「嗯，思路清晰」（同:76）。学员无相猜方位「从赤口被速喜火克，亥时。断西边的是输家，生水之象，断输给北边的人，有道理吗？」（同:267），维护者不采纳：「这个还得看时间，不是千遍一律的」（同:301）「就是时辰对谁来说是得势的」（同:303）。
- **推导链条**：
  1. 以问卦时间取三数 → 得速喜／留连／留连（后更正天宫为赤口）。
  2. 落宫留连 → 对赌运断辞“留连为平、略输”→ 输赢相抵，战况焦灼。
  3. 断方位改用“第一宫”而非落宫 → 天宫赤口为西位。
  4. 实测坐在“北方偏西”→ 近北为水、水耗金，故西位受北牵而成西北。
- **应验**：输赢——卦主「散人师兄断的还是比较准的」（同:86，C）；方位——维护者问「如果按赤口起的话，竹清是坐西北位的吗」（同:217），卦主答「是北方偏西，因为楼不是正方位」（同:221）「我在房子里是正北，但楼本身角度偏西，就成西北了」（同:227）。
- **本案的口径价值**：立“方位取起卦第一宫、不取末宫”；立“起错卦怎么办”的处置——先认错「这卦错了」（同:163）「一个人算错卦很正常」（同:187），但坚持「最重要的是理论不能错」（同:195）；并把赌运断辞限死在玩牌类问法上「比如玩麻将比较适用以上的理论」（同:100）「玩牌九相对参考时又不一样」（同:102）。

#### C-03 昨天几点睡、今天几点起、做什么工作

- **何人问／所问原话**：大浪淘沙（群友、卦主，C 级）。三问连发：「好的 请测一下 我昨天几点休息的？」（02_讲课_邵一尘老师小六壬群预测实例讲解.txt:11）「好的 我今天几点起来的？」（同:66）第三问由维护者点题「大家可以测一下大浪淘沙的工作」（同:280）。
- **起卦**（**全批材料里唯一把取数算式写全的一处**）：
  - 第一问：取问卦人打出消息的时间数字。「我们来看大浪淘沙的问卦时间：20、48、21」（同:129）「正好是符合小六壬取三数要求」（同:131）「20除6余2、48除6余6、21除6余3，得263，落宫为速喜」（同:135）「按整喜取数，为亥时未」（同:139）。余数为 0 时：材料里只有学员一句「无余为六是吧」，维护者未表态（C 级存疑）；按 的口径，见 0 取 10。
  - 第二问：「216」（同:161，学员无相报数），三宫「流连大安空亡」（同:165）；维护者「对，得大安，以大安落宫，在卯时未」（同:167）。
  - 第三问：「留连留连大安」（同:226–227，维护者自报）。
- **三宫**：263：留连／空亡／速喜；216：留连／大安／空亡；第三问：留连／留连／大安。
- **断语要点**（A 维护者）：
  - 第一问：未直言睡点，学员天一居士自陈「所以我断十一」（同:59，C）。卦主实际「我昨天十一点多睡的」（同:41）「快十一点半了」（同:43）。
  - 第二问：「七点不到点」（同:176）「或七点左右」（同:178）。延后之理：「大安往后走为留连，说明是大安未了」（同:251）「所以为卯时尾」（同:253）「说明他醒了之后没有马上起床，且拖延两次」（同:236）。
  - 第三问：先取六亲「刚才所得是大安，我们五行六亲关系工作是什么关系？」（同:325）「比如我克者为妻财」（同:327）「克敌者为官鬼」（同:331）→ 大安属木，克木者为金 → 「小六壬五行为金是哪一个卦」（同:341）「赤口」（同:347）。再限缩：「首先接前卦，留连留连大安，懒散，身未动，所以，不可以是公检法部门」（同:373）「那么，我再给点提示，现在是亥时，五行为水，赤口为金，金生水之象」（同:389）「多为服务行业」（同:397）「而即是服务行业，又不动身的，类似坐办公室的」（同:399）「动口不动身的」（同:409）。
- **推导链条**：
  1. 20÷6 余 2、48÷6 余 0 作 6、21÷6 余 3 → 数字 2、6、3 → 留连、空亡、速喜（余 0 作 6，是本案明写的规则）。
  2. 落宫速喜，用宫数定时 → “按整喜取数，为亥时未”，断在亥时末（近二十三时），卦主报十一点半前后睡。
  3. 第二问 216：留连／大安／空亡，维护者取大安为断点 → 大安在卯 → 大安之后紧接留连即“大安未了” → 落到卯时尾 → 断“七点不到点”。
  4. 第三问：落宫大安（木）→ 克我者为官鬼，金 → 六宫中金为赤口 → 职业类象走赤口。
  5. 时辰亥（水）＋赤口（金）→ 金生水为力量生出 → 服务行业；再叠前卦“身未动、懒散”→ 坐办公室、动口不动身 → 播音员一类。
- **应验**：第二问应（起于七点前后）；第三问由卦主判决「哈哈老师测的基本正确」（同:453）——学员猜“播音员”“老师”，维护者自评「播音员，老师都对」（同:423），又自陈「如果让我测，我最大的可能会测老师」（同:431）「不过，我的答案是错的」（同:435）。
- **本案的口径价值**：立“网上问卦取问卦人打出消息的时刻作三数”并给出余 0 作 6 的算法；立“留连＝拖延、大安未了＝时尾”；示范一卦多问各起一盘；并把维护者的取舍观写死——「其实，答案是什么并不是很重要」（同:417）「重要的是大家可以通过这一事件而得到启悟」（同:421），推理过程重于结论。

### 丙、婚姻与感情

#### C-04 前男友与分手过程

- **何人问／所问原话**：心如止水（群友、卦主，C 级，女，大二）。问句未逐字收录，由维护者转述得知问的是前男友：「赤口、小吉、大安--因你的提问中已告之前男友，说明已分手。」（14_讲课_2012-4-23邵先生卦例.txt:3）
- **起卦**：卦主自带卦来问，宫位直接给出“赤口、小吉、大安”，三数未给。因不是当场起卦，体用改按断卦当时的时辰取（见“口径价值”）。
- **三宫**：天宫赤口　地宫小吉　人宫大安。三宫又作天时、地利、人和读：「嗯，天时、地利、人和」（同:504）「人是大安，天代表缘份，为赤口，两人的关系就确定了」（同:507）。
- **断语要点**（除注明外均 A 维护者）：
  - 分手定性：「分手原因是在一起常争吵，争吵的原因其实主要在你，但你却当时没认识到，总是责怪他的错。你们刚认识时挺聊得来的，有共同语言，在一起后，就慢慢的容易争吵了」（同:3）
  - 生肖：「卦为赤口起，当事人属鸡猴」（同:111）「看我道家小六壬的理论，赤口为金，地支属鸡猴」（同:116）「那么什么是生金的，土嘛」（同:122）；由土生金推对方「那么他很可能是属狗或牛」（同:69）「特别是牛」（同:72）
  - 时间线：「你们应该是在09年的下半年认识的，当时是他追的你」（同:42）「分手的话，应在11年有过，彻底分手是12年过了立春之后」（同:184）「嗯，11年肯定会分手，只是缘份在12年才彻底尽了」（同:295）
  - 现状：「分手后，女方对男方还心存念想，男方身未动，说明已经没有真心想和女方在一起了」（同:187）
  - 追与被追翻转：「09年是男追女的，10年的话就是女追男了」（同:277）「因为，一个是土生金，一个是金克木」（同:280）
  - 逐宫配时段：「第二卦象，小吉时，已在半年期了，那时，他会外出，也指外遇、桃花第，小吉为流水嘛」（同:371）「第三卦象，大安，为现在时，为结果」（同:374）
  - 后事：「不过，他的现任女友极有可能也会分手，到时有可能会吃回头草，但切不可再和他在一起」（同:329）
  - 体用与太极点：「那么，我们再以赤口为太极点」（同:514）「庚寅年，金克木，所以，在那一年会恋爱」（同:517）「没分析小吉的体用，因为刚才这些还用不到」（同:550）「但卦的中心体还是女的」（同:556）「在分析时，转换太极点」（同:559）
- **推导链条**：
  1. 天宫赤口（金）与人宫大安（木）相克 → 关系性质为相克 → 常争吵；起因落在地宫小吉（水），水生木、金生水，故争吵“主要在你”。
  2. 赤口属金，地支配鸡、猴 → 当事人属猴（卦主确认）。
  3. 生金者为土 → 对方取土类属相（狗、牛）——此步断错，实为羊，改断羊、龙。
  4. 人宫大安为现在时 → 大安身未动 → 男方不再有真心。
  5. 地宫小吉为流水 → 半年之后一段 → 外出、外遇、桃花。
  6. 以赤口为太极点看年份：庚寅年金克木 → 该年成恋爱。
- **应验**（卦主逐条反馈，C 级）：生肖女方应（同:57“猴”）；对方不应（同:84“他羊”），维护者自认「晕，我倒数了，不好意思」（同:93）并改断；认识时间错一年（邵断 09 年下半年，卦主“10年9月份”同:133），维护者自评「其实这样也不算误差了，因为我肯定了10年恋爱，只是在认识年份上错了，但理论上没错，是我分析上的出错。」（同:566）；出轨应（同:235“半年说的那个应该是他出轨”）；分手节点大致应（同:202、同:274）；心态应（同:208）；谁追谁应（同:262“而且是我追他的”）；争吵起因先错后改（邵断钱财工作，卦主否认“就是女人”同:386，邵改口“女人倒也可能，比劫嘛，为吃醋之象”同:398）。
- **本案的口径价值**：立“赤口属金、地支鸡猴”与“生金者为土”的取属相法（同时给出断错时的自认范例）；立“卦不是自己出的，体用只能按断卦当时的时辰取”——并把年份断错归到这一步（同:526）；立“逐宫配时段”——天宫定初、地宫定半年后、人宫定现在；并留一条取卦纪律「我从不让别人出牌，大家也应如此，这样才更准」（同:350）。

#### C-05 感情何去何从（三易的完整演示）

- **何人问／所问原话**：材料只以“一滴水”标这一案（求测方，C 级），未收其提问原话，问的是感情能否和好、往何处去。
- **起卦**：月日时，亥时起卦（夜测）。
- **三宫**：天宫大安　地宫速喜　人宫留连；落宫留连。
- **断语要点**（全为 A 维护者）：
  - 三宫分段：「大安是事情的开始，速喜是中间过程，」（04_讲课_2011.8.14 小六壬案例，开示小六壬，三易。.txt:680）「也是发生问题的原因」（同:681）「留连看结果」（同:549）
  - 前两宫不重吉凶：「在这里，前两卦主要为过程，吉凶就不很重要了」（同:748）
  - 逐宫取象：「大安为青龙木，说明你们刚开始发展的挺好的」（同:741）「速喜为朱雀，代表了口舌，说明你们之后常有口舌之争」（同:749）「有停留、纠缠、拖延之意、为小凶」（同:563）
  - 三易的口径：「留连为小凶，这就是不易，不变的原则」（同:449）「而变易呢，就是之后的趋势」（同:450）「我们还是要从留连去断吉凶，这是不易」（同:649）「以变易断之后的可能」（同:651）
  - 变易的五个关系：「土外为吉，也就是说还有希望」（同:588）「但是克外即为主动」（同:591）「如果是生内，就是她会主动找你。」（同:598）「如果是比肩，那么只需打个电话，请看电影，马上和好了」（同:604）「如果是克内，就是大凶，她已无意，很难挽回了」（同:611）「如果是生外，就是你有意她无意，多劳亦无益」（同:620）
  - 性别：「留连为阴卦，对女性有利」（同:658）
  - 与求测人说法相左时：「卦象上有争吵，就一定会争吵」（同:784）
- **推导链条**：
  1. 天宫大安（青龙木）→ 开头好、发展顺、彼此有共同语言。
  2. 地宫速喜（朱雀火）→ 中段口舌、常吵；此宫在本案同时兼作“出事的原因”。
  3. 人宫留连 → 结果为停留、纠缠、拖延，属小凶 → 当下先断“暂时停止了发展”。
  4. 变易：落宫留连（土）与起卦时辰亥（水）比 → 卦克时辰＝克外 → 主吉、要主动去求 → 之后仍有可能和好。
  5. 求测人为女性，留连为阴卦 → 对她有利，成功可能更大。
- **应验**：材料未给应验。
- **本案的口径价值**：三易的唯一完整示范——**不易先把当下断死（留连小凶＝停滞），变易再说后面还有没有可能（克外＝有希望）**，两层不许互相抹掉；同时给出变易的实操入口：拿时辰与落宫比，得出克外／克内／生内／生外／比肩五格；并立“卦上有争吵就一定争吵”，求测人说“分手后才吵”也不撤回，只把它算在过程里。

#### C-06 今年可结婚否（报 466）

- **何人问／所问原话**：男，二十八岁（材料未给昵称，C 级卦主）。问“今年可结婚”，问句以维护者复述为准。
- **起卦**：报数起卦，报 466，得赤口、速喜、留连；戌时。
- **三宫**：天宫赤口　地宫速喜　人宫留连；落宫留连。
- **断语要点**（全为 A 维护者）：
  - 直断：「其实这个卦很简单，落宫留连，留连为停留，为延迟之意，所以，你问今年可结婚，即表示不能结婚。」（60_讲课_小六壬实例（测婚期） 2012.05.18.txt:17）
  - 真正的题目：「不是什么时候结婚的问题，而是你们应该解决两地分居的问题。」（同:21）
  - 以速喜为心：「你们看这个卦虽然结果是留连，但问题关健在哪，在速喜宫呢」（同:444）「整个事件以地利为中心，而他问的又是感情，这感情是不是与地有关？」（同:486）「速喜又为婚姻感情宫」（同:291）
  - 纠纷落在房产：「结果坤土无非为房产、土地」（同:120）「然后为田宅吵架，地利火又生土，说明为此事纠结」（同:137）
  - 两地：「然后，断卦时为戍时，体用关系为一阳土一阴土，这不正好说明，两人为两地分居关系吗」（同:149）「如果是两土属性相同，那可断为一地」（同:162）
  - 起因与认识之年：「赤口为起因，你们认识是因为业务认识的，因为赤口为争吵、纠纷，也为合作、谈判，从两者更多的可能，当然是业务、合作的可能性大了。」（同:35）「赤口起因克年份，庚寅年金克木，为事件起因，也为他们的认识年」（同:201）
  - 三宫分段：「天时赤口金为原因，地利速喜为过程，人和留连为结果」（同:117）
  - 禁推下一宫：「赤口为天时，必有纠纷，速喜为地利，克天时赤口」（同:594）「速喜下一宫是赤口----不要推下一宫」（同:558）「我上次在群里看到有人说什么藏卦法，这一理论我不认同」（同:567）
  - 和好之时：「对，赤口天时生水了，为消耗了，两人气都降了，同时水克速喜火，为地利之事暂时搁下了」（同:618）
- **推导链条**：
  1. 报 466 起出赤口／速喜／留连，戌时。
  2. 落宫留连（土）→ 停留、延迟 → 今年不成。
  3. 婚事不能只看落宫：速喜居地利，速喜为婚姻感情宫，故以速喜为太极点。
  4. 地利速喜（火）生落宫留连（土）→ 恋情推着事走，但留连坤土为田宅 → 卡在房产。
  5. 戌时（土）与留连（土）→ 体用一阳土一阴土 → 两人两地分居。
  6. 天时赤口（金）为起因 → 因业务、合作认识；庚寅年金克木 → 定认识之年。
  7. 争吵之季直取天时宫（金＝秋），不许自中宫再推一宫。
- **应验**：材料未给应验。
- **本案的口径价值**：立“婚姻事以速喜宫为太极点，落宫只作结果”；立留连＝田宅宫、婚事纠纷落在房产；立“一阳土一阴土断两地、同属性断一地”；并明确否掉“藏卦法／推下一宫”这一路。

#### C-07 问能否结婚（转太极）

- **何人问／所问原话**：卦主属猴（同:517），材料未给昵称（C 级）；同一人先问痘坑，第二问改问能否结婚。问句未逐字收录。

- **三宫**：留连／留连／速喜；改问婚姻后落宫转赤口（三宫同转之值见“存疑”）。
- **断语要点**（全为 A 维护者）：
  - 转宫与断语：「速喜转赤口，戌时，你喜欢的难成，但会有喜欢你的，你只要调整心态，当然能结婚」（30_讲课_2013.01.21邵一尘老师卦例解析（孕否及感情二例）.txt:445）
  - 对方信息：「女方信息看大安」（同:539）「1米54至1米59之间」（同:547）
  - 何时出现：「何时出现看留连」（同:465）「2是排位，取年用，2年后，应在羊年。」（同:480）
  - 成事之年：「属猴为申金，相应赤口，同为金，羊年土生金，多在羊年成」（同:517）「恋爱的话，明后年都有可能，成事应在羊年」（同:676）

- **本案的口径价值**：转太极改问的完整一例——**同一个盘，落宫可以从速喜转到赤口，断语随之换**；两条取年法并列（宫位排位取年、生肖同气取生年），都落到羊年，可互校；同时给出转太极的前置条件（要年龄、生肖、三宫全转）。

### 丁、孕产

#### C-08 女友是否怀孕（第一例）

- **何人问／所问原话**：学员代同学起卦，卦主归属一度不清；维护者先追问「谁问的卦？谁起的卦？卦主谁？」（30_讲课_2013.01.21邵一尘老师卦例解析（孕否及感情二例）.txt:160），并说「一开始问你卦主是谁等，也是在看此卦是否有问题，起卦是否有问题」（同:369）。问的是未婚女友是否怀孕，问句未逐字收录。
- **起卦**：三宫小吉／留连／大安，酉时；取数方式材料未给。
- **三宫**：天宫小吉　地宫留连　人宫大安；落宫大安。
- **断语要点**（全为 A 维护者）：
  - 两说并列：「只从大安看，身未动，主不孕」（同:184）「但天时小吉为动，为桃花、为男女之欢，天时生人宫大安，主受孕。」（同:188）；同场先说「只从大安看，应主未孕」（同:170）、「从三宫看，有孕」（同:172）。
  - 中间宫：「地宫留连，留连为暖昧，亦为留在此处，与天宫相承关系即发生关系，有孕，留连又为子宫」（同:192）
  - 当下与之后：「人宫大安，指目前安全、安在、健康」（同:194）「体用，用克体，指之后发展，可能会流产，打掉等」（同:196）
  - 主次：「任何卦都要以落宫为主进行判断」（同:242）「前两宫只看事情的可能性」（同:236）
  - 三宫的性质：「天、地、人，三宫是指前因、经过、结果，这就是一个事情的相承关系，至于体用只判断之后的事情的发展方向的吉凶，与本卦目前状况无关」（同:216）
  - 问什么答什么：「卦问吉凶则断吉凶，卦不问吉凶，只分析结果」（同:224）
  - 取数与验孕：「小吉是发生关系的日子，可以以此判断那天是几月几日，而大安是现在已怀孕多少天了」（同:331）「那也不能说明一定未孕」（同:248）「比如时间还没到」（同:250）
- **推导链条**：
  1. 落宫大安 → 身未动 → 单看此宫主未孕。
  2. 但天宫小吉为动、为桃花、为男女之欢，且小吉（水）生人宫大安（木）→ 合三宫看主受孕。
  3. 地宫留连为暧昧、为子宫，与天时相承 → 已发生关系。
  4. 人宫大安 → 当下平安、安在、健康。
  5. 体用为用克体 → 之后可能流产或打掉——体用只断之后，不改当下的结论。
  6. 应期取数：天时小吉定发生关系之日，落宫大安取数定已孕天数。
- **应验**：卦主报女友在安全期、试纸一条线；维护者「那么如果是这样，没怀孕的可能性就更大一点」（同:293），仍不认卦错：「那也不能说明一定未孕」（同:248），并把口子留在「科学也会有错，卦也会有错」（同:284）。
- **本案的口径价值**：立“任何卦都要以落宫为主”这条总纲的现场用法；同案演示两说并列（独看落宫 vs 合三宫）而不调和；立“体用只断之后、不断当下”；并留下“验孕与卦相反时如何处”的态度样本——归因于时间未到，不归因于卦错。

#### C-09 以后能否怀孕（第二例）

- **何人问／所问原话**：材料未给昵称（C 级卦主）；问“以后能否怀孕”，问句未逐字收录。
- **起卦**：三宫小吉／留连／空亡，子时；取数方式材料未给。
- **三宫**：天宫小吉　地宫留连　人宫空亡；落宫空亡。
- **断语要点**（A 维护者）：「空亡为没有怀上，男方身体有问题，少精或死精…」（同:272）
- **推导链条**：落宫空亡 → 空亡主落空 → 断没怀上；再由空亡一宫指男方身体。**从“没怀上”到“男方身体有问题”之间的步骤，材料未给**，此案只能照结论记，不可当可复算的链条用。
- **应验**：材料未给应验。
- **本案的口径价值**：落宫空亡在孕产一门上的直断法（空亡＝没怀上，并指男方）；同时也是“材料只给结论、不给推导”的样本——遇此类案子只能引结论，不许替它补中间环节。

### 戊、伤灾与疾病

#### C-10 两姐弟被车撞

- **何人问／所问原话**：群友（C 级）报信与反馈，未出提问句；由维护者主动起卦解说。事由为两姐弟在马路上溜冰被汽车撞伤：「不是，那两个孩子在马路上溜冰」（35_讲课_2015年1月5日小孩车祸案例.txt:95）「穿着溜冰鞋」（同:96）。
- **起卦**：按“我所知的第一时间”起，以起卦者本人为太极点。「十一月十五，亥时~~小吉，大安，空亡，亥时」（同:2）「按现在的时间起的」（同:5）。原则：「其实像这种卦例，严格来讲，要按车祸发生的时间来起卦，如果不知车祸时间，要按即时消息来起卦，也就是你知道的第一时间」（同:14）「我现在起的是我所知的第一时间」（同:17）「这个灵机点是以我为中心，为太极点的」（同:23）。
- **三宫**：天宫小吉　地宫大安　人宫空亡；亥时。转太极点后「速喜、空亡、小吉」（同:276），落宫小吉。
- **断语要点**（全为 A 维护者）：
  - 定主体：「从卦象分析，以第三宫落宫看目前结果」（同:32）「转太极点，土克水，小吉为当事人」（同:50）「算的是车祸，然后转太极后算的是受伤的当事人，包括开车的和被撞的」（同:77）

#### C-12 一岁半女孩发烧

- **何人问／所问原话**：材料未给昵称（C 级卦主），问的是一岁半女孩的病，问句未逐字收录。

- **断语要点**（全为 A 维护者）：
  - 土性：「大家要记住土的特性，特别是空亡的特性，土为杂性，最易交杂…」（13_讲课_邵先生解析卦例（斷病）.txt:106）
  - 三宫串读：「天时宫为空亡为起因，然后地利宫为速喜为火，为传播传染，也就是在土日或土时被父母传染了炎症，人宫速喜为结果，为炎症或上火，但两个速喜，又加之午时又为火，刚多为发烧之象」（同:172）

  - 应期：「6天为一转折，因为6为水，第6日可基本好转，第9日康复」（同:481）「以卜卦日算起」（同:505）「比如克日没有，泄日也是，369日取最符合的一日便是」（同:680）
  - 得病之日：「对，找阳土的日子」（同:418）「我之前巳经说过了，土日或土时得病」（同:424）
  - 标本：「因为火是目前的状况，土是起始之因」（同:817）「嗯，泄火为标，疏胃为本」（同:808）「所以说，要标本兼治」（同:850）
  - 虚实：「还好，空亡在前，在后为虚」（同:856）

### 己、行人

#### C-13 失联的背包客（三宫具象法唯一完整演示）

- **何人问／所问原话**：求测一方为女性（事主），材料未给昵称（C 级）；问失联的背包客下落与同行情况，问句未逐字收录。
- **起卦**：月日时三宫速喜／速喜／空亡，申时；三数未给。维护者在此盘上再排三宫具象法。
- **三宫／三盘**：三宫速喜（天）、速喜（地）、空亡（人）。天盘得兑、地盘得巽、人盘得离。三组为：第一组 赤口／赤口／小吉；第二组 大安／大安／速喜；第三组 初排 留连／留连／赤口，**当场改正为大安／大安／速喜**。
- **断语要点**（全为 A 维护者）：
  - 用法与限度：「我们分三宫具象法，看一下前因后果」（68_讲课_预测背包客案例（三宫具象法解说）.txt:115）「所以，三宫具象法我很少用」（同:437）「一般只在复杂的长时间的不变变化的情况下才用」（同:725）「越拆细，越容易出错」（同:944）
  - 空亡：「这个卦应是某个事情落空了之意，比如飞机延误，机票没买到等等」（同:88）「空亡原本就代表没事，失去联系而巳」（同:446）
  - 起卦排法：「先得天盘的八卦具象」（同:577）「把天盘的速喜放中间，为天人合一，得阴阳阳」（同:580）「天盘的排列：人、天、地，地盘的排列：天、地、人，人盘的排列：天、人、地。」（同:612）「天盘的排列：人、空亡、阴，天、速喜、阳，地、速喜、阳，」（同:663）
  - 三组：「然后，我们再看，速喜宫与兑卦五行为克外，三宫全克一遍，作为第一宫的三宫。」（同:700）「速喜克完后是赤口、再赤口，空亡克完是小吉。」（同:705）「第二宫，巽卦与速喜为生出」（同:708）「第三宫，空亡与离，为生进，速喜生留连或空亡，因事主是女的，为阴」（同:746）「得留连」（同:747）
  - 读象：「三个全阴卦」（同:121）「那这样的话，就是全部女的了，也就符合了全阴卦了」（同:190）「有一个年纪比她小的女孩一同前往的吗」（同:123）「由于赤口为天地宫，小吉为人」（同:211）「原因是交易或语言上引起的」（同:212）「天、地均为大安，大安身未动，所以，一直在一个地方」（同:230）「看最后一宫，赤口落宫，就怀疑有可能是会受点伤」（同:467）
  - 复盘认错：「只是怀疑她有可能会受点小伤或受困错了」（同:405）「当时把生出生进搞错了」（同:818）「如果不用三宫具象法，这个卦就不会有丁点的失误了」（同:443）
  - 事后的补读：「离卦也代表联系方式，也代表传播，也代表网络」（同:485）「大安为身未动，留连为停留在此处，原理是一样的」（同:913）「只有最后的速喜代表很快会有回音，而赤口则一时不会有回应」（同:916）
- **推导链条**：
  1. 天盘：把天宫的速喜放中间，按“人、天、地”排 → 空亡（阴）、速喜（阳）、速喜（阳）→ 得兑卦。
  2. 地盘：按“天、地、人”排 → 得巽卦；人盘：按“天、人、地”排 → 得离卦。地盘三宫即原卦。
  3. 第一组：落宫速喜与兑卦为克外 → 三宫全克一遍 → 速喜克完是赤口、再赤口；空亡克完是小吉 → 赤口／赤口／小吉。
  4. 第二组：巽卦与第二宫速喜为生出 → 大安／大安／速喜。
  5. 第三组：空亡与离为生进；速喜可生留连或空亡，事主为女属阴 → 取留连 → 留连／留连／赤口（**此步当场认错，应为大安／大安／速喜**）。
  6. 读象：三卦全阴 → 同行全女；有比她小的女孩；赤口占天地宫 → 争执起于交易或语言；天地皆大安 → 一直待在一个地方没挪窝；末宫赤口 → 一时不会有回应、疑受困受伤。
- **应验**：当事人平安到家（维护者自述复盘前提），同行者确为全女并含比她小的女孩（先按全阴断女、再据此问出实况）；而“受点伤／被扣押”这一路是错的，维护者自评「只是怀疑她有可能会受点小伤或受困错了」（同:405）。
- **本案的口径价值**：**三宫具象法全库唯一的完整演示**，从起三盘到读象一步不缺；同时是“一格错则断语跟着错”的标本——错在把“生出”与“生进”搞反；并留下一句最要紧的自我限定「如果不用三宫具象法，这个卦就不会有丁点的失误了」（同:443），说明这一法不是常规盘法。

### 庚、天气

#### C-14 甲子日雨转晴与时辰

- **何人问／所问原话**：材料未给昵称（C 级）；问某日天气（何时雨止转晴），问句未逐字收录。
- **起卦**：三宫赤口／大安／速喜；当日为甲子日。
- **三宫**：天宫赤口　地宫大安　人宫速喜；落宫速喜。
- **断语要点**（全为 A 维护者）：
  - 六神天气底表：「大安晴、留连细雨、速喜晴、赤口暴雨、小吉雨、空亡阴」（17_讲课_2012-7-22邵先生卦例（天氣相關）.txt:40）「先以六神自主定义为主，再参看其」（同:37）
  - 大安不是大晴：「大安虽为晴，但为阴睛天气，即为晴却不见太阳这样的天气，或阴晴不定，在这里是雨止转晴的阶段」（同:108）
  - 三宫连读：「这个天气是典型的雨转晴」（同:102）「速喜为晴，见太阳，有些情况还会见彩虹」（同:111）
  - 时辰段：「正确的应该是戌时雨，亥时大，子时小，丑时止，寅时晴…」（同:281）「由于是生，会适当延误」（同:290）
  - 温度：「甲木生速喜火，36度最高温度，子水克速喜火，29度最低温度」（同:247）「非精准，基本温度」（同:250）
  - 风向：「天时起风处，地利为去向，落宫为偏…」（同:401）「答案：西北风」（同:404）
  - 各宫所受之生：「赤口土来生，大安水来生，速喜木来生…」（同:365）
  - 用途：「我断天气也不是很多，因为现在都有天气预报了，一般给人挑结婚日子之后，会卜一卦，因为也许挑的日子是下一年的某一天，那么，天气预测不可能有那么久，只能卜卦看看那天天气如何」（同:327）
- **推导链条**：
  1. 三宫不作三种独立天气，按先后读成过程：天宫赤口（暴雨）→ 地宫大安（雨止、阴晴不定）→ 人宫速喜（晴、见太阳）→ 雨转晴。
  2. 甲子日：甲木生落宫速喜火 → 最高 36 度；子水克速喜火 → 最低 29 度（维护者自标非精准）。
  3. 日干支与落宫为生（水生木）→ “生则延误”→ 整段时辰后延一辰 → 戌时雨、亥时大、子时小、丑时止、寅时晴。
  4. 风向分三宫取：天时为起风处（赤口，西）、地利为去向（大安，东）、落宫为偏（速喜，南）→ 合成西北风，再按当地当季常风校正。
- **应验**：材料未给应验。
- **本案的口径价值**：示范“三宫连读作过程”而非三个独立天象；立“先定日干支再排时辰”“生则延误、克则速变”；温度不取宫数而取生克（学员据“速喜369”报 36.9 度，维护者不用，改按日干生日支克给 36／29）——这一处取舍在别处又会见到相反的用法，见“存疑与矛盾”。

  - 头宫：「留连，为遗失在某处，留在了某处」（同:153）
  - 中宫：「留在了何处？小吉水，餐厅消费处」（同:156）「去食堂问吧」（同:33）「小吉为过程，为动，说明已有人动过了」（同:162）「也就是说，你丢了之后马上被人拿了」（同:170）
  - 落宫：「速喜为传播，也就是说有人看到了」（同:176）「整个卦以速喜为落宫」（同:179）「有一定的可能找回」（同:182）
  - 体用：「然后体生用，为耗，说明你要主动的想办法去找才行」（同:194）「主动的去找还是有希望的」（同:203）「因为你是在酉时丢的，当时去找是能找到的，为火克金」（同:303）「你当时问我时是戌时，火生土，体生用，为消耗，为就算去找了也不一定会找到」（同:305）
  - 找法的用意：「因为你去找了，对方就会关注到，怕被人说出来，还不如主动的还你」（同:289）「你去找是为了让你搞出动静」（同:323）
  - 应期：「因为昨天你已经过了有利的时间了」（同:268）「所以，你会在今天的巳午时找到」（同:271）
  - 判别格：「如果是赤口为天时，小吉为地宫，那么则很有可能是被偷了」（同:337）
  - 学员说法（C 级）：天津-出来炸道提出「老师，落宫好像是卦给人的启示，教人怎么做，若是大安，就是不让动」（同:211），维护者答「是的」（同:215），又补「还得看体用」（同:218）。
- **推导链条**：
  1. 头宫留连 → 东西没离开，遗失在某个地方。
  2. 中宫小吉（水）→ 取五行类象“餐厅、消费处”→ 断在食堂；小吉为动 → 已被人拿动过。
  3. 落宫速喜 → 速喜主传播 → 有人看见，有找回的可能，但不作必回断。
  4. 体用按“落宫为体、时辰为用”：问卦时戌（土），体速喜（火）生用（土）→ 体生用为耗 → 必须主动去找。
  5. 再比丢时的时辰：酉（金），体速喜（火）克用（金）→ 体克用 → 当时去找本来能找到；可惜已过。
  6. 有利时辰已过 → 应期顺延到次日同一气的巳午时。
- **应验**：应验于应期——断“今天的巳午时找到”，实反馈为当日上午十点五十分来电，落在巳时。
- **本案的口径价值**：寻物用**问卦当下的时间**起卦而非丢失时刻；三宫分工最清楚的一案（头宫＝还在不在、中宫＝落在何处＋被人动过、落宫＝有无可能找回）；立“丢时与问时分别看体用”——同一个卦，换个时辰体用就反过来；并立“赤口为天时、小吉为地宫才断被偷”这一判别格。

### 壬、风水

#### C-16 宅之吉凶（宅基压水）

- **何人问／所问原话**：宅主（材料未给昵称，C 级）；问宅之吉凶，问句未逐字收录。
- **起卦**：三宫速喜／空亡／小吉，巳时；维护者另嘱「测风水卦最好让来人报数，这样准确率才高」（28_讲课_2013-5-5邵先生讲解（风水相关）.txt:94）。
- **三宫**：天宫速喜　地宫空亡　人宫小吉；落宫小吉。
- **断语要点**（全为 A 维护者）：
  - 次序：「定坐向是第一步，第二步是观物象，第三步是判吉凶」（同:181）「如果向定错了就应该是错卦」（同:36）
  - 定向：「小六壬看风水，首先以天时宫为向，地宫为座，这里的座是指偏，而非真正的座」（同:45）「以宅为准」（同:48）「比如这个卦，天宫为速喜、为南，所以，基本向为南」（同:51）「地宫空亡，空亡居中，所以可以读为正南」（同:54）「另外，天宫地宫相同也为正向」（同:58）
  - 精度：「不过，座向不一定百分百的精准，只要八卦向对就行，24 山的话基本不看」（同:39）「也就是说，一个向在45 度范围内就算对了」（同:64）
  - 入气：「然后人宫是代表入气位」（同:75）「假如是农村的，代表北院门、来路等」（同:78）
  - 主断：「首先，地落空亡人在小吉，断房子盖在了水井或河流之上了」（同:272）
  - 财与人：「那么，对应的会是财空，也就是不积财或积隐晦之财」（同:278）「如果是当官有权的之类的，此人必受贿」（同:281）「另一个，则对应人，家中中子会离家出门，如果仅一子，那么此子也会离家出门」（同:295）「或者做运输、物流、司机之类的流动性的行业，因小吉虽为动，但不一定动」（同:298）
  - 相冲：「向与入气相冲不以外出论，而是以争吵论」（同:322）
  - 内外局：「简单的讲以楼盘座向定外环镜，以门向定内环镜！」（同:239）
  - 排八方：「另外，速喜、空亡、小吉、巳时，巳为东南，代表东南有火」（同:326）「就是把速喜转到东南，留连转到正东，大安转到东北，留连转到正北」（同:335）
  - 交代口径：「一般判断时不以什么方向跟卦主说的，而是以房子的前面，后面，左边、右边说」（同:414）
- **推导链条**：
  1. 定向：天宫速喜为南 → 基本向为南；地宫空亡居中 → 可读正南（若要偏，空亡为艮、座偏东北，向便偏西南）。
  2. 人宫为入气位 → 小吉。
  3. 判吉凶：地宫空亡（土、落空）＋ 人宫小吉（水）→ 宅基压水，断房子盖在水井或河流之上。
  4. 财上应空：不积财，或转为暗财。
  5. 人上应动：中子离家；仅一子也离家，或做运输、物流、司机一类流动性行业。
  6. 天宫（向）与人宫（入气）相冲 → 不作出外断，改断家中争吵不和睦。
  7. 外局按八方逆排：速喜定东南，其余依次转位，每方再合该方八卦类象读（东南三角煞、正东为路或小河、东北为大树电线杆、正北有靠山而不正、西北低洼水坑）。
- **应验**：卦主反馈「就是建在水上了」（同:275）——主断（宅基压水）应。
- **本案的口径价值**：风水三步次序（定向→观物象→判吉凶）的唯一完整演示；立“天时宫为向、地宫为座（座指偏，不是真坐山）”“以宅为准不以门为准”“八卦向 45 度内算对”；立内外两局分定；立“对卦主只讲前后左右，不讲罗盘方位”。

### 癸、事业与合作

#### C-17 四个工作选哪一个

- **何人问／所问原话**：在职者（材料未给昵称，C 级）；问四项工作哪个更适合，问句未逐字收录。
- **起卦**：月日时，三宫赤口／留连／大安，亥时。
- **三宫**：天宫赤口　地宫留连　人宫大安；落宫大安。
- **断语要点**（全为 A 维护者）：
  - 落宫取意：「是大安身未动嘛」（49_讲课_2023-5-23-邵先生讲解工作四选一的解卦思路.txt:379）「身未动就是工作不换」（同:380）「那么就是不要换，就是现在所选择的当下的是最好的。」（同:386）
  - 体用：「落宫大安，体用是用生体」（同:404）「那也就是意味着大安这个工作是好的」（同:405）
  - 四路比：「怎么选择呢？大安啊，大安代表的东方。」（同:411）「因为落宫大安，体用是北方啊，水生木的啊」（同:414）「我讲的这些思路不是说你必须完全用上啊」（同:541）
  - 按所求归堆：「那么这个工作相对更容易升职啊」（同:436）「更容易为自己带来利益」（同:437）「这个工作相对会更轻松，更有贵人运，各方面的这个环境会更好一点。」（同:439）
  - 官：「那刚才讲了赤口是克大安的，为官。」（同:453）
  - 创业：「是要按速喜给他看啊」（同:470）「基本上可以划掉了啊」（同:471）「除非你有更详细的创业方案啊」（同:472）
  - 结论：「还是这个第四个公司更好」（同:490）「那么可能第二个会更轻松一点啊，当然你的追求是什么啊」（同:503）
  - 边界：「所以说用卜卦来卜终身卦，其实这个不太靠谱啊。」（同:320）「他可能指的是现阶段的好与坏，并不指你终身啊这个工作好与坏」（同:332）
- **推导链条**：
  1. 落宫大安 → 身未动 → 现在这份不换；维护者据此直接把“当下这份”列为最优。
  2. 体用为用生体 → 落宫所代表的那份工作是好的。
  3. 四路比四选项：① 类象（第四项奢侈品按大安论）；② 方位（大安主东，体用水在北方，水生木）；③ 行业类别（被体用水所生者优）；④ 所求（升职归赤口、得利归留连、轻松归小吉、平顺拓展归大安）。
  4. 创业一项：卦中无速喜也按速喜取象，大安木生火为生出 → 付出多回报少 → 排除。
  5. 结论：第四项最合大安，次为第二项（轻松、有贵人），第三项排除；追求不同次序可换。
- **应验**：材料未给应验。
- **本案的口径价值**：多选一断法的骨架（类象／方位／类别／所求四路）；立“落宫先取其意（身未动即不换），不取其象与理”；立“六宫按所求分堆”（赤口升职、留连得利、小吉轻松、大安平顺）；并立一条边界：卜卦只断现阶段，不卜终身职业。

#### C-18 三人合作投资

- **何人问／所问原话**：第三方代起卦；卦主为女性，是三人合伙人之一（维护者先追问“你不是股东？”37_讲课_2016-8-29邵一尘老师讲解（合作投资）.txt:41）。问合作能否成，问句未逐字收录。
- **起卦**：三宫赤口／大安／赤口，申时；起卦方式材料未给。
- **三宫**：天宫赤口　地宫大安　人宫赤口；落宫赤口。
- **断语要点**（全为 A 维护者）：
  - 主断：「赤口落宫，肯定协商意见不统一或有争执，但因体用比助，恰巧是合作之事，所以，会有协商一致的假象，但实则茅盾暗藏，在以后的合作中埋下伏笔，会常有意见不同之事。」（同:54）
  - 比助的范围：「这里大家要注意一个现象，如果不是因为合作之事，赤口落宫，体用比助不一定有什么大的作用」（同:57）「这里不分阴阳，凡合作之事，遇比肩都为助」（同:68）
  - 三宫各应一方：「我们再延伸来看，既然是三个人合作，我们已知卦主赤口落宫为女，又正符天地人格局，天为赤口，地为大安，可以推断，另两人一人为女，一为男」（同:80）「男的得地势，另一女得天势，卦主得人势」（同:86）
  - 三方角色：「得天势，基本上代表投资方或官方，有权势」（同:108）「又或者是投资人，大股东」（同:114）「地宫的男的，大安，大安为技术型，又落地宫，这男的基本属于投资项目的技术人员或懂行的人，又或者是有场地，有设备或其它条件的人」（同:135）「而卦主，因为是落人宫，又为赤口，有游说，口才之意；得人和，所以，多是中间游说谈判的那个人」（同:138）
  - 两女一男：「天与人比肩，两女的容易意见统一，男的比较吃亏，二女斗一男之势很明显，但是反过来，赤口与赤口又是比劫，两女的也会斗嘴」（同:89）
  - 克不动：「天赤口阴金克大安阳木，相克却克不动」（同:154）「也就是有意投资却投不动，心有余而力不足」（同:161）「也可能是资金不足或较难到位，或最终投资的资金与预期减少等情况的发生」（同:179）
  - 项目性质：「金克木，为动，说明是一项改造，修整，打造，破坏相关方面的项目」（同:306）
  - 投资额：「看地宫与天宫的系，木为项目，金为投资，资金是水，金生水，水生木」（同:373）「水为小吉，以小吉宫断投资金额」（同:376）
  - 选址：「选址方面主要看地宫，大安落地宫，选址没什么太大的问题，但因天与人克地，可能租金会较高，招人会因难，或者投资人或卦主会对场地不满意等情况的发生」（同:182）
  - 收口：「再回到主题，结果刚才已经断了，叫形合意不合，目前看，谈判应该是算成功的，但之后还是会有问题，甚至最后不欢而散，这个大家看以后鼓王的反馈了」（同:145）「因为他问的是合作的结果，不欢而散基本是指最终合作没成功」（同:191）
  - 没问的不断：「其实没问的问题，我们原则上是不去断的，更不应去转太极」（同:349）
- **推导链条**：
  1. 落宫赤口 → 协商意见不统一、有争执。
  2. 体用比助（申时金与赤口金同气）→ 只给出“协商一致”的表象 → 形合意不合，日后仍会分歧。
  3. 三宫各应一方：天宫赤口为一方（女，得势＝投资方／权势）、地宫大安为一方（男，技术／场地条件）、人宫赤口为卦主（女，游说谈判）。
  4. 天宫（阴金）克地宫（阳木）→ 相克却克不动 → 想投投不动、资金不足或不到位。
  5. 项目：金克木为动 → 改造、修整、打造类；资金五行由金生水得水 → 以小吉宫断投资额。
  6. 选址看地宫：地宫本身无碍，但天、人两宫皆克之 → 租金偏高、招人不易。
- **应验**：当日反馈三方已达成共识（谈判谈成了）；**“甚至最后不欢而散”这一层，材料未给后续反馈**——即只验到“形合”。“意不合”未验也未否。
- **本案的口径价值**：立“同宫比肩／比劫在合作类问事上作助、在别的事上不作数”；立「三宫各应一方」（天＝权势方、地＝技术／场地方、人＝卦主）；立“克不动”在钱上的落点（资金不到位）；并示范“没问的不断”——追问年龄、长相时维护者不转太极、只读三宫直接带着的信息。

## 四、存疑与矛盾清单

### 甲、两说并存（均出自维护者，不替其调和）

1. **落宫取第几宫，同一场问答里不一致。** C-03 第一问 263，取第三宫速喜为落宫：「20除6余2、48除6余6、21除6余3，得263，落宫为速喜」（02_讲课_邵一尘老师小六壬群预测实例讲解.txt:135）；第二问 216 三宫为“流连大安空亡”，维护者却说「对，得大安，以大安落宫，在卯时未」（同:167）——按同一算法，第三宫应是空亡。两处取法不同，维护者未解释。
2. **同一问、同一时辰，起出两套三宫。** C-01 里遊塵散人起“赤口、留連、大安”，天天天蓝起「空亡，速喜，留连」（20_讲课_2012年5月10日邵老师断卦辞编.txt:110），两套并存；维护者以「嗯，大致都对」（同:76）一并收下，未裁断。
3. **“克”的吉凶方向两说。** 学员把天宫赤口克人宫大安读成凶「其一，天宮赤口，緣分有損，且傷人宮大安，乃“天不助我”之意。」（同:69），维护者改成中性「天时赤口克大安，为不得时运，但克为考察，说明从天时来看，还得考察一阵子」（同:84）——同一句卦，一凶一中性，维护者未撤回学员的解。
4. **起卦数错了，按错卦断仍然准。** C-02 维护者承认 22 点应起赤口而误提速喜「22应该是赤口，而非速喜」（21_讲课_2012年5月11日邵老师解卦案例.txt:171），游尘按错卦所断仍被卦主评为「散人师兄断的还是比较准的」（同:86）；维护者只承认「一个人算错卦很正常」（同:187）「最重要的是理论不能错」（同:195），未说明错卦为何仍验。学员给的圆场「不過，錯卦按照錯卦斷，結果正確，也是“天意”」（同:175）属 C 级，不作规则。
5. **同一卦，两人结论相反。** C-02 卦主自断「如果抛开自己知道结果单从卦象看我断先赢后输，求财不得。」（同:55），游尘断「綜上，打牌勝敗參半，勝多輸少」（同:74）；维护者未裁断谁的结论对，只评「嗯，思路清晰」（同:76）。
6. **赌运能不能靠方位与时辰加力，两说。** 一段是亲身经历「我多年前有一段时间长期算体彩排列三，赚了几万元，后来就慢慢的不准了，最终赚的都还回去了」（同:203），一段又答「但事实上，我们赌牌，可以通过方位与时间来得到一定的助力，从而更能赢牌」（同:140）。两头并存。
7. **空亡的阴阳，同一案里取值相反。** 取爻成卦时空亡当阴用「天盘的排列：人、空亡、阴，天、速喜、阳，地、速喜、阳，」（68_讲课_预测背包客案例（三宫具象法解说）.txt:663）；选第三组要取留连还是空亡时又说「空亡与留连两土，留连为阴，空亡为阳」（同:755）。
8. **成卦三爻次序在同段内自相矛盾。** 同一份材料先写「按阴阴阳，得出兑卦」（同:669），紧接着又写「阴阳阳」（同:672）；按 663 行的三个宫位记录，对得上的是阴、阳、阳。
9. **生男生女：口径已定，留档一套相反说法。** 主口径：大安、小吉、空亡为男，留连、速喜、赤口为女（60_讲课_小六壬实例（测婚期） 2012.05.18.txt:765、768）；大安、小吉、留连另有女性几率（66_讲课_邵一尘老师讲孕生男女.txt:5、6；口径）。群友整理稿另记一套「大安、留连、空亡为男，速喜、赤口、小吉为女」（66_讲课_邵一尘老师讲孕生男女.txt:3），与主口径在留连、小吉两宫相反——只留档，不作主用。
10. **孕否同场两说并列。** 「只从大安看，身未动，主不孕」（30_讲课_2013.01.21邵一尘老师卦例解析（孕否及感情二例）.txt:184）与「但天时小吉为动，为桃花、为男女之欢，天时生人宫大安，主受孕。」（同:188）同案并存，维护者未合并成一个判据。
11. **温度取宫数还是取生克。** 先抛「速喜369」（17_讲课_2012-7-22邵先生卦例（天氣相關）.txt:222），学员据此报 36.9 度，维护者不用，改按日干生日支克给「甲木生速喜火，36度最高温度，子水克速喜火，29度最低温度」（同:247）。是“宫数不当温度用”还是“本例只是巧合”，材料未明说。
12. **背包客案第二组与改正后的第三组，转录记成同一值。** 第二组为“大安、大安、速喜”，第三组改正后亦为“大安、大安、速喜”——两组若真同值，则“第二宫”与“第三宫”无从区分；此处须回原始记录核，本库暂按原记并列。

### 乙、存疑（性质上不能当铁律）

### 丙、留白（材料未给，不补）

## 五、拿哪几个当训练样例

| 用途 | 用哪一案 | 为什么 |
|---|---|---|
| 学“起卦→三宫→断语”的整条路 | C-03 | 全库唯一把取数算式写全的（20／48／21→263，余 0 作 6），可自己算一遍再对答案 |
| 学“转太极点换主体” | C-10 | 第三方代起卦，主体从起卦人换到当事人，包含取象、人数、生死关口与应期 |
| 学“三宫分工”最干净的一案 | C-15 | 头宫＝还在不在、中宫＝落在何处、落宫＝有无可能找回；还能看到丢时与问时体用互换 |

| 学多主体盘（合作） | C-18 | 三宫各应一方、克不动、形合意不合，一条线走到底 |
| **反面样本：错卦为何仍准** | C-02 | 起错宫位，断语仍被评准；学员的“天意”说法不可当规则 |
| **反面样本：一格错则全盘偏** | C-13 | 三宫具象法唯一完整演示，同时把“生出／生进”搞反的代价演给人看 |
