# 莫高窟主题配色试版 · 

## 研究来源与界限

- 敦煌研究院文化创意研究中心：https://www.dha.ac.cn/info/1204/2362.htm
- 敦煌研究院云南文博会官方现场照片：https://www.dha.ac.cn/info/1018/7037.htm
- China Daily / China Bound 的敦煌文创产品介绍与供图：https://www.chinabound.cn/s/202602/05/WS69843f17498e23165e06d48b/dunhuang-inspiration-dun-huang-wen-chuang.html

实际查看了研究院展场、产品陈列和文创书签礼盒、莲花杯、鹿灯礼盒照片。展场有大面积赭红与暖白；书签礼盒使用深青绿衬底和金色边线，饰件有暖白、朱红、青绿；杯具系列使用矿物蓝、绿、红、黄与金色基座；鹿灯盒使用亮橙与白金。所参考的产品属于不同系列，不将其合称为敦煌研究院统一品牌色。照片受光照、印刷与屏幕影响，以下 HEX 为本项目自行设计的界面色，不是壁画实测色或官方标准色。参考照片不进入 App。

## 当前问题与设计取舍

早先那一版偏橙的棕底、黄褐文字和大面积橙金雾相叠，文字与底色的色相过近；新增群青雾又与偏黄的卡面缺少协调。保留深色主题与提灯入窟定位，以低饱和炭褐为稳定底，石青和石绿作为动态颜色，暖白用于阅读，赭金只用于强调；暖赭雾减少面积。沿用现有界面结构与随机游走，不增加装饰图案。

雾气 strength 从 0.48 降至 0.36（参数降低 25%，不代表每个像素亮度降低相同比例），暖赭浓度另乘 0.72；内部暗化由 10–30% 收为 8–20%。旧系统 PNG 回退素材同步采用相同三色。没有把新配色扩到其他皮肤。

## 修改位置

- pages/Skin.kt：SKINS 的 mg 项，统一页面、卡片、文字、边线、强调与功能色。
- androidApp/.../fog/RealtimeFogView.kt：setSkin 的 mg 雾色/浓度及着色器暖色权重和暗部。
- scripts/gen-fog.py 与 assets/common/fog/mg-*-flow.png、mg-*-wisp.png：旧系统回退雾色。

先编译调试版并装入模拟器，观感由用户打开确认；不打正式包。

## 第二版：按莲花杯配色关系重做

现象上一版过灰偏阴冷。改为深群青 #192B4B 作底、卡面 #243957、金黄强调 #E6B95B、暖白文字 #FFF1D8；雾用矿物蓝 #427DC2、青绿 #389F8D 与少量朱红 #CE6550。这些仍是参考产品照片的屏幕转译，不是官方发布色号。保留形变与随机游走，strength 从 0.36 收到 0.29，提高色彩辨识度的同时控制大面积覆盖。暖色雾仍按 0.72 权重，不引入金色满屏发光。

## 当前采用：回到原版暖褐、金、群青

用户否定前两次整套重配色，要求在最初版本上加工。已恢复原版 bg/surface/surface2、主文字、强调、描边和功能色。只将 dim 从 #C0A98C 微提至 #C8B496、dim2 从 #9C8768 微提至 #AF997A。实时雾恢复原版金 #D69C42、群青 #38669A、暖褐 #9D572E；strength 取 0.34，相比用户认可形状时的 0.48 收淡约 29%。保留不规则雾形、内部柔暗部与全屏随机游走，不回退到椭圆 PNG。前两版仅为已否定的研究试验，不是当前设计。
